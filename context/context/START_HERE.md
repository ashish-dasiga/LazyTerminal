# Lazy Terminal — Shared Context Pack

This is the shared source-of-truth pack for all four contributors and Antigravity sessions.

- `source-specification/`: extracted architecture/specification kit.

## Important naming note
The original spec uses the working title “Mobile–PC Development Environment” and the frontend uses “Remote Development System.” For this project, use **Lazy Terminal** as the product name, as agreed by the owner. Do not alter the supplied UI branding or visuals unless explicitly authorized.
